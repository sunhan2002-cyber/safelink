# Safe Link UI Writing Guide v5.0

> 기준 자료: `Safe_Link_UI_Writing_Guide_v4.0.md`, `Safe_Link_UI_Writing_Guide_v4.2.md`, `android/`
>
> 적용 원칙: Android의 실제 Compose Screen과 Navigation 순서를 따른다. 버튼·상태·문구는 화면 코드에 바로 적용할 수 있도록 작성하며, 아직 화면 또는 기능이 없는 항목은 **연동 시 적용**으로 표시한다.

## 1. 문구 원칙

- 짧고 단정하게 작성합니다. 한 문장에는 한 가지 행동 또는 상태만 안내합니다.
- 사용자의 판단을 존중합니다. 단정적 표현 대신 확인·상담·신고를 안내합니다.
- 위험 상황에서는 행동을 먼저 제시합니다. 긴 설명은 보조 문구로 제공합니다.
- 분석 결과는 참고 정보로 안내합니다. 분석 결과가 사실 또는 피해를 확정하는 것처럼 표현하지 않습니다.
- 기관별 명칭, 전화번호, 운영 시간 등은 실제 데이터로 교체되어도 자연스러운 문구를 사용합니다.

## 2. 용어 통일

| 사용하지 않는 용어 | 사용할 용어 |
| --- | --- |
| 상담기관 | 지원기관 |
| 추천기관 | 즉시 대응기관 / 추가 지원기관 |
| 기관 안내 | 기관 추천 |
| 웹 연결 | 홈페이지 이동 |
| AI 결과 | 분석 결과 |

위 용어는 버튼, 제목, 설명, 오류, 알림에 동일하게 적용합니다.

## 15. DetectionResultScreen

### Description

- 분석 결과
- 분석 결과는 참고 정보이며 최종 판단은 사용자에게 있습니다.

### State

#### 위험 유형

- `{위험 유형} 위험 신호가 감지되었습니다.`
- 현재 대화에서 확인된 위험 신호입니다.

#### 위험도

| 위험도 | 안내 문구 |
| --- | --- |
| 안전 | 현재 분석된 대화에서 뚜렷한 위험 신호는 발견되지 않았습니다. |
| 주의 | 주의가 필요한 표현이 확인되었습니다. 상대방의 요청을 다시 확인해 보세요. |
| 경고 | 위험 가능성이 높은 표현이 확인되었습니다. 송금이나 개인정보 제공은 신중하게 판단하세요. |
| 긴급 | 즉시 대응이 필요한 위험 신호가 확인되었습니다. 가까운 즉시 대응기관의 도움을 받는 것을 권장합니다. |

#### 분석 근거

- 감지된 위험 요소
- 대화 하이라이트
- `{감지 문구}`
- `{위험 요소명} · {설명}`

매칭 항목이 없을 때는 다음 문구를 사용한다.

- 위험한 표현이 감지되지 않았습니다.

#### 기관 추천

현재 화면은 추천 기관을 순위순으로 하나의 목록에 표시한다. 실제 데이터에서 기관 그룹을 구분할 수 있을 때 아래 제목을 사용한다.

**즉시 대응기관**

- 현재 위험 유형에 가장 적합한 기관입니다.
- `{순위}. {기관명}`
- `{전화번호}`

**추가 지원기관**

- 피해 회복, 상담, 법률 및 복지 지원을 받을 수 있는 기관입니다.
- `{순위}. {기관명}`
- `{전화번호}`

**추천 이유**

- 현재 위험 유형과 위험도를 바탕으로 안내한 기관입니다.
- `{추천 이유}`

추천할 기관이 없을 때는 다음 문구를 사용한다.

- 지금은 특정 기관을 안내할 만큼 명확한 위험 신호가 아닙니다. 계속 주의해 주세요.

### Button

- 대응 가이드 보기
- 지원기관 연결
- 전화하기
- 홈페이지 이동
- 다시 분석

`DetectionResultScreen`의 현재 구현 버튼은 **대응 가이드 보기**, **전문가 상담 연결**이다. 전화하기, 홈페이지 이동, 다시 분석은 기관 카드·재분석 흐름이 연결될 때 위 문구로 사용한다.

### Guide

- 실제 공공기관은 전화로 송금이나 비밀번호를 요구하지 않습니다.
- 긴급한 상황이라면 즉시 112에 신고해 주세요.

### Error

분석 결과 또는 기관 추천 데이터 조회에 실패했을 때 사용한다.

- 분석 결과를 불러오지 못했습니다. 다시 시도해 주세요.
- 기관 추천 정보를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.

### Toast

기록 저장 또는 외부 연결 기능이 연결될 때 사용한다.

- 분석이 완료되었습니다.
- 분석 기록이 저장되었습니다.
- 전화 연결을 시작합니다.
- 홈페이지를 여는 중입니다.

## 16. ResponseGuideScreen

### Description

- 대응 가이드
- 위험 신호가 감지되었을 때 이렇게 대응하세요.

### Guide

- STEP 01. 즉시 연락을 차단하세요.
- STEP 02. URL과 의심스러운 링크를 열지 마세요.
- STEP 03. 개인정보와 금융 정보를 보호하세요.
- 공공기관은 전화나 문자로 공문을 보내지 않습니다.
- 본인 인증을 위한 송환 요청은 100% 사기입니다.
- 출처가 분명하지 않은 앱 설치 요청은 위험합니다.
- 상황이 지속되거나 피해가 발생한 경우 지원기관의 도움을 받으세요.

### Button

- 긴급 도움 요청
- 112 전화
- 1332 전화
- 지원기관 보기
- 메인 화면으로 돌아가기

`긴급 도움 요청`은 긴급 위험도에서만 표시한다.

### Dialog

전화 연결 기능이 연결될 때 사용한다.

**제목:** 112로 전화할까요?

**설명:** 전화 앱으로 이동합니다.

**버튼:** 전화하기 / 취소

## 21. 공통 오류·알림 문구

다음 문구는 실제 기능이 연결된 화면에서만 사용한다. 현재 Compose 화면에 전역 오류·Toast·Push Notification UI는 구현되어 있지 않다.

### Error

- 인터넷 연결을 확인한 후 다시 시도해 주세요.
- 요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.
- 필요한 정보를 불러오지 못했습니다. 다시 시도해 주세요.

### Push Notification

| 상황 | 문구 |
| --- | --- |
| 위험 감지 | 위험 가능성이 있는 대화가 감지되었습니다. 확인해 보세요. |
| 분석 완료 | 분석이 완료되었습니다. 결과를 확인해 주세요. |
| 긴급 | 즉시 대응이 필요한 위험 신호가 확인되었습니다. |

### Maintenance

- 서비스 점검 중입니다.
- 잠시 후 다시 이용해 주세요.
