# 신기훈 7주차 결과물 01 - 규칙 반영 현황 정리 (점수 반영 vs AI 진입조건 전용)

> 팀 공통 문제의식: "1차 분석이 키워드 중심처럼 보인다." 이 문서는 **지금 어떤 규칙이
> 실제로 1차(온디바이스) 점수에 반영되고, 어떤 건 아직 "AI를 부를지 말지" 판단에만
> 쓰이는지**를 한눈에 정리한다. 김선한 보고서("현재 분석 한계와 보완 방향"), 김우영
> 문구 작업의 근거 자료로 바로 쓸 수 있게 작성함.

---

## 1. 결론 요약

**1차 분석(`DetectionEngine.analyze()`)은 키워드 매칭만 하지 않는다.** 아래 3개 층이
전부 실제 점수에 반영된다:

1. **키워드** (`match_type: keyword`/`regex-simple`, 116개) — 원문 부분일치/정규식
2. **문장 규칙** (`match_type: regex-complex`, 1개 + `numeric_ratio_pattern` 콤보 1개) — 숫자 조건부 판정
3. **상황 규칙** (`repeat_pattern`/`long_session_pattern` 콤보, 2개) — 세션 전체 반복/장기흐름

**AI 진입 조건에만 쓰이고 점수에는 반영 안 되는 것**은 딱 2가지로 좁혀져 있다(5주차에
정리 완료) — 회색지대 점수 구간, 신규 subcategory 신뢰도 게이팅. 아래 표 참고.

---

## 2. 규칙별 반영 위치 전수 표

| 규칙 종류 | 개수 | 1차 점수 반영 | AI 진입 조건 | 비고 |
|---|---|:---:|:---:|---|
| 키워드(`keyword`) | 111개 | ✅ | - | 원문 부분일치 |
| 정규식(`regex-simple`) | 5개 | ✅ (2개는 `structural_only`로 점수 0, 콤보 트리거 전용) | - | 전화번호/URL 등 |
| 문장 규칙(`regex-complex`) | 1개 (RS-2-9-003) | ✅ | - | 숫자 캡처+임계값 조건부 매칭 |
| 콤보: `general` | 2개 (3CAT/4CAT) | ✅ | - | 서로 다른 중분류 3개+/4개+ 동시 감지 |
| 콤보: `specific` | 9개 | ✅ | - | 특정 subcategory 조합(all-of) |
| 콤보: `repeat_pattern`(상황 규칙) | 1개 (GL 반복) | ✅ | - | 가스라이팅 반복 2회+ |
| 콤보: `long_session_pattern`(상황 규칙) | 1개 (RS 장기세션) | ✅ | - | 15턴+ (현재 UI는 turns=1 고정이라 사실상 미발동, 07번 문서 참고) |
| 콤보: `numeric_ratio_pattern`(문장 규칙) | 1개 (RS 수익률) | ✅ (matchedKeywords/category엔 미반영) | - | 두 숫자 증가율 계산 |
| **회색지대 점수 구간** | 20-40, 55-70 | ❌ | ✅ | 점수 자체가 애매한 구간일 때만 |
| **신규 subcategory 신뢰도 게이팅** | 8개 subcategory | ❌ | ✅ | 실사용 검증 전까지 한시적 |
| **수동 신고** | - | ❌ | ✅ | 사용자 입력, 텍스트 분석 결과 아님 |

**AI 진입 조건에만 쓰이는 3개**(회색지대/신규subcategory/수동신고)는 전부 "이 텍스트
자체의 위험 신호"가 아니라 "판단이 애매하니 한 번 더 확인이 필요하다"는 성격이라서
1차 점수에 넣지 않는 게 맞다고 판단해서 의도적으로 분리해뒀다(5주차 결정 유지).

---

## 3. 완료 기준 대응

- ✅ "1차 분석이 더 이상 키워드만 보는 구조처럼 설명되면 안 됨" — 위 표에서 문장/상황
  규칙이 실제 점수 계산 경로에 있음을 확인 가능
- ✅ "문장/상황 규칙이 실제 점수 계산에 반영된 근거를 보여줄 수 있어야 함" —
  `DetectionResult.sentenceRuleEvidences`/`situationalRuleEvidences`(6주차)가 결과
  화면에도 실제로 렌더링됨

## 4. 발표/보고서용 한 줄 요약 (김선한/김우영 참고)

> "SafeLink의 1차 분석은 키워드 매칭뿐 아니라, 문장 안의 숫자 조건(문장 규칙)과 세션
> 전체의 반복·흐름 패턴(상황 규칙)까지 온디바이스에서 함께 계산한다. AI 보조분석은
> 이 온디바이스 판단이 애매한 극히 일부 구간에서만 보조적으로 개입한다."
