# 필수 화면 목록 최종본

## 목적

SafeLink의 1차 개발에 반드시 포함되어야 하는 화면을 확정한다.
기준은 현재까지 정리된 프로젝트 설명 문서, 기술 방향, GitHub 업로드 결과물, 피그마 초안이다.

## 필수 화면 선정 기준

- 위험 감지부터 대응까지 핵심 흐름에 직접 필요한 화면인가
- 다음 주부터 Android 화면 구현에 바로 들어갈 수 있는가
- 피그마 초안 또는 기존 문서에서 이미 방향이 잡혀 있는가
- 자가진단, 감지, 기록, 대응, 추천, 설정의 핵심 기능을 포함하는가

## 필수 화면 목록

### 1. 스플래시 화면

- 앱 실행 시 가장 먼저 보이는 시작 화면
- SafeLink 로고와 앱 진입 이미지를 보여주는 화면
- 앱 첫인상과 브랜드 통일에 필요

### 2. 온보딩 화면

- SafeLink가 어떤 앱인지 간단히 설명하는 소개 화면
- 위험 감지, 대응 가이드, 지원 연결 기능을 사용자에게 처음 안내하는 역할
- `시작하기` 버튼을 통해 메인 화면으로 이동

### 3. 홈 대시보드 화면

- 앱의 중심이 되는 메인 화면
- 현재 안전 상태, 자가진단 진입, 스크린샷 분석 진입, 추천 서비스 진입 기능 포함
- 사용자가 가장 자주 진입하는 기본 허브 화면

### 4. 자가진단 화면

- 체크리스트 기반으로 현재 상황의 위험도를 점검하는 화면
- 사용자가 직접 항목에 응답하여 위험 여부를 1차로 확인하는 기능
- SafeLink 핵심 기능 중 하나이므로 필수

### 5. 자가진단 결과 화면

- 자가진단 완료 후 위험도 결과를 보여주는 화면
- 결과 단계, 요약 설명, 다음 행동 가이드를 함께 보여줘야 함
- 단순 체크리스트에서 끝나지 않고 대응으로 연결하기 위해 필요

### 6. 스크린샷/텍스트 분석 입력 화면

- 스크린샷 업로드 또는 텍스트 입력을 통해 위험 문장을 분석 요청하는 화면
- OCR 또는 텍스트 기반 분석의 출발점이 되는 화면
- 분석 기능 진입 화면으로 필수

### 7. 분석 진행 중 화면

- 사용자가 분석이 실제로 진행 중임을 인지할 수 있는 상태 화면
- 업로드 상태, 진행률, 분석 중 메시지 등을 표시
- 피그마 초안에도 존재하며 사용자 경험상 필요

### 8. 분석 결과 화면

- 위험 문장 분석 결과와 위험도 수준을 보여주는 화면
- 주의/경고/긴급 등의 분류와 분석 요약이 포함되어야 함
- 대응 가이드 및 지원 서비스 화면으로 연결되는 핵심 화면

### 9. 대응 가이드 화면

- 위험 상황별로 바로 취할 행동을 단계별로 안내하는 화면
- 단순 탐지에서 끝나지 않고 실질적 대응을 연결하는 SafeLink 핵심 차별점 화면

### 10. 지원 서비스 추천 화면

- 상황에 맞는 기관, 상담, 신고, 지원 자원을 추천하는 화면
- 기관 설명, 연락 방식, 연결 버튼 등의 정보 제공
- SafeLink의 핵심 목표인 지원 연결을 담당하므로 필수

### 11. 활동 기록 화면

- 자가진단 결과, 분석 결과, 과거 기록을 확인하는 화면
- 날짜별 기록과 위험 단계 태그를 보여주는 구조
- 추후 재확인과 기록 관리 기능을 위해 필요

### 12. 설정 화면

- 앱 잠금, 생체인증, 알림 설정 등 기본 환경설정을 조정하는 화면
- 보안성과 개인화 설정을 위해 필요

## 필수 화면 간단 분류

### 진입 화면

- 스플래시 화면
- 온보딩 화면
- 홈 대시보드 화면

### 분석/판단 화면

- 자가진단 화면
- 자가진단 결과 화면
- 스크린샷/텍스트 분석 입력 화면
- 분석 진행 중 화면
- 분석 결과 화면

### 대응/지원 화면

- 대응 가이드 화면
- 지원 서비스 추천 화면

### 관리/보조 화면

- 활동 기록 화면
- 설정 화면

## 현재 기준에서 후순위로 보는 화면

아래 화면들은 필요성은 있지만, 현재 1차 필수 화면에서는 후순위로 둔다.

- 긴급 요청 전용 독립 화면
- 기관 상세 화면
- 잠금 해제 전용 독립 화면
- 알림 상세 이력 화면
- 신고 접수 완료 전용 화면

이 화면들은 1차 구현 과정에서 필요성이 커지면 추가하는 방향으로 본다.

## 최종 정리

현재 SafeLink 1차 개발 기준 필수 화면은 총 12개로 본다.

- 스플래시 화면
- 온보딩 화면
- 홈 대시보드 화면
- 자가진단 화면
- 자가진단 결과 화면
- 스크린샷/텍스트 분석 입력 화면
- 분석 진행 중 화면
- 분석 결과 화면
- 대응 가이드 화면
- 지원 서비스 추천 화면
- 활동 기록 화면
- 설정 화면

위 화면들을 기준으로 다음 문서인 `화면 흐름 요약본`을 작성한다.
