# 화면 흐름 요약본

## 목적

SafeLink의 필수 화면들이 어떤 순서와 관계로 연결되는지 정리한다.
이 문서는 다음 주 Android 화면 전환 구조와 기능 우선 구현 순서를 정하는 기준으로 사용한다.

## 기본 흐름

SafeLink의 전체 흐름은 아래 4개 축으로 본다.

- 앱 진입 흐름
- 자가진단 흐름
- 스크린샷/텍스트 분석 흐름
- 대응/기록/설정 흐름

## 1. 앱 진입 흐름

`스플래시 화면 -> 온보딩 화면 -> 홈 대시보드 화면`

### 설명

- 사용자는 앱을 실행하면 먼저 스플래시 화면을 본다.
- 첫 실행 또는 서비스 소개가 필요한 경우 온보딩 화면으로 이동한다.
- 온보딩에서 `시작하기`를 누르면 홈 대시보드 화면으로 진입한다.
- 이후 기본 허브는 항상 홈 대시보드 화면이다.

## 2. 자가진단 흐름

`홈 대시보드 화면 -> 자가진단 화면 -> 자가진단 결과 화면 -> 대응 가이드 화면 또는 지원 서비스 추천 화면`

### 설명

- 사용자는 홈에서 자가진단 기능으로 진입한다.
- 자가진단 화면에서 체크리스트 문항에 응답한다.
- 응답이 끝나면 자가진단 결과 화면으로 이동한다.
- 결과 화면에서는 위험도 수준과 요약 설명을 보여준다.
- 결과에 따라 대응 가이드 화면 또는 지원 서비스 추천 화면으로 이어진다.
- 자가진단 결과는 활동 기록 화면에도 저장되는 구조로 연결한다.

## 3. 스크린샷/텍스트 분석 흐름

`홈 대시보드 화면 -> 스크린샷/텍스트 분석 입력 화면 -> 분석 진행 중 화면 -> 분석 결과 화면 -> 대응 가이드 화면 또는 지원 서비스 추천 화면`

### 설명

- 사용자는 홈에서 스크린샷 분석 또는 텍스트 분석 기능으로 진입한다.
- 입력 화면에서 스크린샷 업로드 또는 텍스트 입력을 진행한다.
- 분석 요청 후 분석 진행 중 화면으로 이동한다.
- 분석이 끝나면 분석 결과 화면에서 위험도, 핵심 문장, 분류 결과를 확인한다.
- 결과에 따라 대응 가이드 화면 또는 지원 서비스 추천 화면으로 이어진다.
- 분석 결과 역시 활동 기록 화면에 남긴다.

## 4. 대응 흐름

`자가진단 결과 화면 또는 분석 결과 화면 -> 대응 가이드 화면`

### 설명

- 대응 가이드 화면은 자가진단 결과 또는 분석 결과에서 공통으로 진입한다.
- 여기서 사용자는 현재 상황에 맞는 행동 가이드를 단계별로 확인한다.
- 필요 시 지원 서비스 추천 화면으로 추가 이동할 수 있다.

## 5. 지원 연결 흐름

`자가진단 결과 화면 또는 분석 결과 화면 또는 대응 가이드 화면 -> 지원 서비스 추천 화면`

### 설명

- 지원 서비스 추천 화면은 여러 결과 화면에서 연결되는 공통 도착 지점이다.
- 사용자는 여기서 기관 정보, 전화 연결, 방문 안내 등 실제 도움 요청 경로를 확인한다.
- SafeLink의 핵심 목표가 감지 이후 지원 연결까지 이어지는 것이므로 중요한 흐름이다.

## 6. 기록 확인 흐름

`홈 대시보드 화면 -> 활동 기록 화면`

### 설명

- 사용자는 홈에서 과거 자가진단 결과, 분석 결과, 위험 기록을 다시 볼 수 있다.
- 활동 기록 화면에서는 날짜별 기록, 위험 단계, 요약 내용, 상세 보기 구조를 가진다.
- 이후 필요한 경우 기록 화면에서 대응 가이드 또는 지원 화면으로 재진입할 수 있도록 확장 가능하다.

## 7. 설정 흐름

`홈 대시보드 화면 -> 설정 화면`

### 설명

- 사용자는 홈에서 설정 화면으로 진입한다.
- 설정 화면에서는 앱 잠금, 생체인증, 알림 설정, 기타 기본 설정을 조정한다.
- 보안성과 개인화 설정을 관리하는 보조 흐름이다.

## 화면 흐름 요약 구조

### 메인 분기

`홈 대시보드 화면`

- 자가진단 화면으로 이동
- 스크린샷/텍스트 분석 입력 화면으로 이동
- 활동 기록 화면으로 이동
- 설정 화면으로 이동
- 지원 서비스 추천 화면으로 바로 이동 가능

### 결과 이후 공통 분기

`자가진단 결과 화면` 또는 `분석 결과 화면`

- 대응 가이드 화면으로 이동
- 지원 서비스 추천 화면으로 이동
- 활동 기록에 저장

## 1차 개발 기준 핵심 사용자 흐름

### 흐름 A. 자가진단 중심

`앱 실행 -> 홈 -> 자가진단 -> 자가진단 결과 -> 대응 가이드 -> 지원 서비스 추천`

### 흐름 B. 분석 중심

`앱 실행 -> 홈 -> 분석 입력 -> 분석 진행 중 -> 분석 결과 -> 대응 가이드 -> 지원 서비스 추천`

### 흐름 C. 기록 재확인 중심

`앱 실행 -> 홈 -> 활동 기록 -> 과거 결과 확인`

### 흐름 D. 설정 관리 중심

`앱 실행 -> 홈 -> 설정`

## 화면 흐름 정리 목적

이 화면 흐름은 다음 작업의 기준이 된다.

- Android 화면 전환 구조 설계
- 화면별 버튼 이동 정의
- API 호출이 필요한 구간 식별
- 다음 주 우선 개발 화면 선정

## 최종 정리

SafeLink의 1차 화면 흐름은 `홈 대시보드`를 중심으로,

- 자가진단 흐름
- 분석 흐름
- 대응/지원 흐름
- 기록/설정 흐름

으로 나뉜다.

핵심은 사용자가 `위험 감지 -> 결과 확인 -> 대응 가이드 -> 지원 연결`까지 자연스럽게 이어지도록 설계하는 것이다.
