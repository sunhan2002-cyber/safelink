# 인스타그램 DM 감지 — 실기기 검증 절차

코드에는 감지 대상으로 이미 추가돼 있습니다(`com.instagram.android`).
남은 건 **인스타그램이 대화 내용을 접근성 트리에 노출하는지** 실기기에서 확인하는 것뿐입니다.

에뮬레이터로는 확인할 수 없습니다 — 인스타 설치에 구글 계정 로그인이, 그다음 인스타 계정 로그인이 필요합니다.

---

## 왜 확인이 필요한가

카카오톡·문자는 표준 TextView 기반이라 화면의 글자가 접근성 트리에 그대로 올라옵니다.
반면 인스타그램은 커스텀 렌더링 비중이 높아, **화면에 글자가 보여도 트리에는 안 올라올 수 있습니다.**
이건 코드로 해결되는 문제가 아니라 상대 앱이 어떻게 만들어졌느냐의 문제라, 직접 찍어봐야 압니다.

> 참고: 이번 작업에서 `contentDescription` 도 함께 읽도록 추출 로직을 보강했습니다.
> 커스텀 렌더링 앱이 말풍선 내용을 `text` 대신 `contentDescription` 에 담는 경우가 있어서,
> 인스타가 그 방식이라면 이것만으로 잡힐 수 있습니다.

---

## 검증 방법 (2분)

### 준비

1. 실기기를 USB로 연결하고 **USB 디버깅**을 켭니다
2. 인스타그램에서 **DM 대화방을 열어 화면에 띄워둡니다** (아무 대화나 괜찮습니다)

### 실행

PC에서 아래를 실행합니다.

```bash
adb shell uiautomator dump /sdcard/insta.xml
adb pull /sdcard/insta.xml .
```

### 판정

`insta.xml` 을 열어 **대화방에 보이는 문장이 파일 안에 있는지** 찾아봅니다.

| 결과 | 의미 | 다음 조치 |
|---|---|---|
| 대화 내용이 보임 | 감지 **가능** | 코드가 이미 준비돼 있으므로 그대로 동작. 실제 위험 문구로 알림까지 확인 |
| `text=""` 만 있고 내용 없음 | 감지 **불가** | 아래 "안 될 경우" 참고 |

찾기 편하게 하려면 대화방에서 특정 단어(예: "안녕")를 보내두고 그 단어로 검색하면 됩니다.

```bash
grep "안녕" insta.xml
```

## 동작 확인 (감지 가능한 경우)

1. SafeLink 설치 후 **설정 > 접근성**에서 SafeLink 켜기
2. 인스타 DM으로 위험 문구를 받아봅니다 (다른 계정에서 보내거나, 본인에게 보내기)
   - 예: `"엄마 나 폰 액정 깨져서 컴퓨터로 보내. 지금 급하게 인증번호 좀 알려줘"`
3. 확인할 것
   - 경고 알림이 뜨는가
   - SafeLink **기록 탭**에 `백그라운드 감지 · (위험유형)` 으로 쌓이는가

---

## 안 될 경우

인스타가 접근성 트리에 대화 내용을 노출하지 않는다면 **앱 쪽에서 할 수 있는 일이 없습니다.**
Android가 제공하는 유일한 합법 경로가 접근성 서비스이고, 그 경로로 안 보이면 방법이 없습니다.

발표에서는 이렇게 설명하는 편이 낫습니다.

> "카카오톡·문자처럼 표준 UI 컴포넌트를 쓰는 앱은 패키지 등록만으로 확장됩니다.
> 다만 인스타그램처럼 자체 렌더링 비중이 높은 앱은 접근성 트리에 텍스트가 노출되지 않아
> 구조적 제약이 있으며, 이 경우 스크린샷 분석 경로로 대응하도록 안내합니다."

실제로 스크린샷 분석(OCR) 경로가 이미 구현돼 있어서, **화면을 캡처해 올리면 동일한 엔진으로 분석됩니다.**
즉 인스타가 막혀도 사용자가 완전히 방법이 없는 건 아닙니다.


설치돼 있지 않은 앱은 이벤트가 오지 않으므로, 목록에 있어도 아무 영향이 없습니다.
