# Claude API 키 설정 (발표용 구성)

> 작성: 김재겸 (2026-09-11)

발표 시연에서는 앱이 **서버를 거치지 않고 Claude 를 직접 호출**합니다.
폰과 PC 서버의 네트워크 연결에 의존하지 않기 위한 팀 결정입니다.
그래서 빌드하는 PC 마다 **Claude API 키를 로컬에 설정**해야 AI 보조분석이 동작합니다.

---

## ⚠️ 키를 절대 저장소에 올리지 마세요

이 저장소는 **공개(public)** 입니다. Anthropic 은 GitHub 시크릿 스캐닝 파트너라서,
공개 저장소에 올라간 Claude API 키는 **GitHub 이 감지해 Anthropic 이 몇 분 안에 자동으로 폐기**합니다.

한 명이라도 실수로 올리면 **팀 전체의 AI 분석이 즉시 멈춥니다** (이미 설치한 APK 포함).

올리면 안 되는 곳:
- 코드, `build.gradle.kts`, `local.properties.example`, README, 문서
- 커밋 메시지, 이슈, PR 댓글
- 팀 단톡방 (1:1 메시지로만 주고받기)

---

## 설정 방법

1. **키 관리자(김재겸)에게 1:1 메시지로 키를 받습니다.** 받은 뒤 메시지는 지워주세요.
2. `android/local.properties.example` 을 참고해, **`android/local.properties`** 에 한 줄을 추가합니다.

   ```properties
   ANTHROPIC_API_KEY=받은_키
   ```

   `local.properties` 는 `.gitignore` 대상이라 git 에 올라가지 않습니다.
   (`local.properties.example` 에는 실제 키를 적지 마세요. 그 파일은 git 에 올라갑니다.)

3. Android Studio 에서 **Gradle Sync** 후 다시 빌드합니다.

### 제대로 됐는지 확인

- 로맨스스캠처럼 AI 호출 대상인 문구를 분석하면, 결과 화면에 **"AI 보조분석"** 카드가 나타납니다.
  (예: `자기야 나 지금 해외 파병 중인데 통관비가 급하게 필요해 300만원만 보내줄 수 있어 돌아가면 꼭 갚을게`)
- Logcat 에서 태그 **`ClaudeDirect`** 로 `AI 분석 완료 (…ms)` 가 찍힙니다.
  앱을 켜면 먼저 `AI 분석 준비 완료` 가 찍힙니다.

### 키가 없으면

앱은 정상 동작합니다. AI 보조분석만 빠지고 온디바이스 판정 결과가 그대로 나옵니다.
(키가 없을 때 AI 요청은 분석 서버 `SAFELINK_AI_BASE_URL` 로 갑니다. 기본값은 에뮬레이터용 `http://10.0.2.2:8000/` 이고, `backend/` 서버를 띄워야 합니다.)

---

## 키가 든 APK 다루기

키를 넣고 빌드한 APK 안에는 **키가 그대로 들어 있습니다.**

- APK 를 GitHub 릴리스·단톡방·드라이브 공개 링크에 올리지 마세요.
- 폰에 설치할 때는 USB 로 직접 옮기거나 Android Studio 에서 바로 설치하세요.

---

## 발표가 끝나면

- 키 관리자가 Claude Console 에서 **키를 폐기**합니다. 이후 이 구성의 APK 에서는 AI 보조분석이 동작하지 않습니다.
- 계속 쓸 경우에는 키를 앱에 넣지 않는 **서버 경유 구성**(`backend/`)으로 돌아가는 것을 권장합니다.

## 참고: 팀원별로 키를 따로 쓰고 싶다면

키 하나를 여럿이 쓰면, 한 명의 실수로 키를 폐기할 때 모두가 영향을 받습니다.
Claude Console 에서 팀원을 조직에 초대하면 각자 자기 키를 만들 수 있고, 문제가 생긴 키만 따로 폐기할 수 있습니다.
