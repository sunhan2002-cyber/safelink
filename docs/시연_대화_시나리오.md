## 시연 전에 알아 둘 것

- **실시간 보호 알림은 경고(31점) 이상**일 때만 뜹니다. 주의 대화는 알림이 뜨지 않고, 텍스트·스크린샷 분석 결과 화면에서 "주의"로 보입니다.
- 실시간 보호에서 10~30점 대화는 AI 보조분석이 켜져 있으면 AI가 한 번 더 확인합니다. AI가 위험하다고 판단하면 알림이 뜰 수 있습니다.
- 예시 링크(`cj-parcel.top` 등)는 **실제로 누르지 마세요.**
- scrcpy에서 한/영이 안 바뀌면 PC에서 문장을 복사한 뒤 scrcpy 창에서 **Ctrl+V**로 붙여넣으세요.
