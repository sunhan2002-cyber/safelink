## 3. 앱 잠금 — PIN 입력 (20:1181) `LockScreen`

| 영역 | 구성 요소 | 설명·동작 |
|---|---|---|
| 상단 | 로고 + 아이덴티티 | SafeLink 방패 로고 |
| 중앙 | 안내 문구 | "PIN 번호를 입력하세요" |
| 중앙 | PIN 도트 4개 | 입력 시 채워짐 |
| 하단 | 숫자 키패드 (0–9, 백스페이스) | 대형 터치 타겟 |
| 하단 | 생체인증 버튼 | 지문 아이콘, BiometricPrompt 호출 |

- **이동**: 인증 성공 → 홈 (또는 복귀 직전 화면)
- **상태**: ①오류 — 도트 빨강 흔들림 + "PIN이 일치하지 않습니다 (n/5회)" ②차단 — 키패드 비활성 + 30초 카운트다운 (Tasks 5.12)
