# 김선한 9주차 02 분석구조 역할구분 확정본

## 목적

- 문장 규칙, 상황 규칙, AI 보조분석의 역할을 명확히 나눠서 발표와 보고서에서 같은 표현을 쓰기 위한 문서이다.

## 구조 한 줄 요약

- 1차는 규칙 기반 위험도 산출, 2차는 AI 보조 판단이다.

## 1차 분석 역할

### 키워드 분석

- 위험 표현 사전에 들어 있는 직접적 표현을 감지한다.
- 예: 송금 요구, 인증번호 요구, 링크 클릭 유도, 기관 사칭 표현
- 장점: 빠르고 명확하다.
- 한계: 표현이 바뀌면 놓칠 수 있다.

### 문장 규칙 분석

- 특정 단어 하나가 아니라 문장 패턴 자체를 본다.
- 예: 숫자 조건이 붙은 금전 요구, 특정 조합 문장, 정규식 기반 복합 패턴
- 역할: 키워드만으로 잡기 어려운 문장형 위험 신호를 보완한다.

### 상황 규칙 분석

- 대화의 반복성, 장기성, 조합 패턴을 본다.
- 예: 반복 압박, 장기 유도, 관계 고립, 지속적 죄책감 유도
- 역할: 한 문장만 봐서는 약하지만 대화 흐름에서 위험해지는 경우를 보완한다.

## 2차 분석 역할

### AI 보조분석

- 1차 분석 결과가 애매하거나 추가 맥락 판단이 필요한 경우에만 사용한다.
- 역할:
  - 회색지대 판단 보완
  - 문맥 요약
  - 패턴 설명 보강
  - 점수 보정

## 역할 구분 핵심 문장

- 키워드 분석은 직접적인 위험 표현을 빠르게 잡는 역할이다.
- 문장 규칙 분석은 표현 패턴을 읽어 키워드 분석의 부족한 부분을 보완하는 역할이다.
- 상황 규칙 분석은 대화 흐름과 반복 구조를 반영해 위험도를 더 현실적으로 계산하는 역할이다.
- AI 보조분석은 1차 분석을 대체하는 것이 아니라, 1차 분석이 애매할 때만 보완하는 역할이다.

## 금지해야 할 설명

- "우리 앱은 AI가 모든 대화를 이해해서 판단한다."
- "키워드만 넣으면 자동으로 학습된다."
- "현재는 완전한 문맥 이해 AI가 구현되어 있다."

## 권장 설명

- "현재 앱은 규칙 기반 분석을 중심으로 동작하고, AI는 추가 판단이 필요할 때만 보조적으로 사용됩니다."
- "위험도는 키워드, 문장 규칙, 상황 규칙을 종합해 계산하고 있습니다."
- "AI는 핵심 분석기라기보다 회색지대 보완 장치에 가깝습니다."

## 완료 기준 대조

- 문장 규칙, 상황 규칙, AI 보조분석 역할이 분리되어 정리되어 있음
- 발표와 보고서에서 쓰면 안 되는 표현과 권장 표현이 구분되어 있음
- 팀원들이 같은 표현으로 설명할 수 있는 공통 문장 기준이 포함되어 있음
