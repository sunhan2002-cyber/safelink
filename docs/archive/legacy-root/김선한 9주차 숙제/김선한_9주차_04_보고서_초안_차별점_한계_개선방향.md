# 김선한 9주차 04 보고서 초안 차별점 한계 개선방향

## 1. 차별점 초안

SafeLink의 차별점은 단순 키워드 탐지에 그치지 않고, 문장 규칙과 상황 규칙을 함께 반영한 1차 온디바이스 분석 후 필요할 때만 AI 보조분석을 수행하는 하이브리드 구조에 있다. 또한 사용자가 직접 입력한 텍스트뿐 아니라 스크린샷 OCR과 백그라운드 감지 흐름까지 연결하여, 위험 신호를 발견한 뒤 대응 가이드와 지원 기관 정보까지 이어주는 실제 피해 예방형 구조를 지향한다.

## 2. 한계 초안

현재 SafeLink는 핵심 분석 흐름과 시연 가능한 기능 구조를 구현했지만, 모든 표현 변형과 긴 문맥형 대화를 완벽하게 이해하는 단계는 아니다. 특히 사용자 입장에서는 아직 분석 결과가 키워드 중심으로 보일 수 있으며, 문장 규칙과 상황 규칙의 범위도 더 확장될 필요가 있다. 백그라운드 감지 역시 현재는 접근성 기반 구조와 일부 대상 앱 중심으로 검증 중이므로, 실제 서비스 수준의 범용성과 안정성은 추가 보완이 필요하다.

## 3. 개선 방향 초안

향후에는 문장 규칙과 상황 규칙의 패턴 수를 확장하고, 더 다양한 실제 유사 대화 사례를 통해 검증 범위를 넓힐 계획이다. 또한 AI 보조분석은 1차 분석을 대체하는 구조가 아니라, 회색지대 판단과 문맥 보완을 위한 보조 장치로 안정화할 예정이다. 기능 측면에서는 감지 대상 앱 범위를 확대하고, 결과 화면에서 분석 근거를 더 직관적으로 보여주도록 개선해 SafeLink의 설명 가능성과 사용자 신뢰도를 높일 것이다.

## 4. 발표/보고서 공통 요약 문장

- SafeLink는 1차 규칙 기반 분석과 2차 AI 보조분석을 결합한 하이브리드 위험 감지 구조를 사용한다.
- 현재는 시연 가능한 핵심 기능을 구현한 단계이며, 정확도와 감지 범위는 지속적으로 확장 중이다.
- 핵심 목표는 위험 신호 감지 자체를 넘어서, 대응 가이드와 지원 기관 연결까지 이어지는 피해 예방형 서비스 구조를 만드는 것이다.
