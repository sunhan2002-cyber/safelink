# 김선한 9주차 03 영상 시연 설명 기준

## 목적

- 영상 시연에서 무엇을 완료 기능으로 설명하고, 무엇을 확장 중 기능으로 설명할지 기준을 확정한다.

## 완료 기능으로 설명할 것

### 1. 기본 분석 흐름

- 홈 화면에서 분석 시작
- 텍스트 입력 또는 스크린샷 선택
- 분석 결과 화면 진입
- 대응 가이드 및 추천 기관 확인

### 2. 1차 위험도 분석

- 키워드 기반 분석
- 문장 규칙 기반 분석
- 상황 규칙 기반 분석
- 위험도 점수와 위험 단계 산출

### 3. 스크린샷 분석 흐름

- 사용자가 스크린샷을 선택하면 OCR로 텍스트를 추출
- 추출된 텍스트가 기존 분석 엔진으로 들어감
- 결과 화면까지 이어지는 흐름 시연 가능

### 4. 백그라운드 감지 구조

- 접근성 권한 기반 감지 구조
- 감지 후 알림 표시
- 감지된 표현 확인
- 대응 가이드 연결

### 5. AI 보조분석 구조

- 1차 분석 후 애매한 경우 AI 보조분석으로 넘어가는 구조
- 결과 화면에서 AI 보조분석 요약과 패턴 근거 확인 가능

## 확장 중 기능으로 설명할 것

### 1. 분석 정확도 확장

- 더 다양한 표현 변형
- 더 긴 맥락형 대화
- 더 많은 위험 패턴

### 2. 감지 범위 확장

- 카카오톡 외 다른 메신저/대화 앱으로 확장
- 백그라운드 감지 대상 확대

### 3. AI 보조분석 안정화

- 실제 서비스 수준의 정확도와 응답 안정성 보강
- 더 다양한 회색지대 사례 대응

## 영상에서 쓰기 좋은 문장

- "현재 SafeLink는 텍스트 입력, 스크린샷 분석, 백그라운드 감지까지 이어지는 핵심 흐름을 구현했습니다."
- "위험도는 키워드, 문장 규칙, 상황 규칙을 종합해 계산되며, 애매한 경우에만 AI 보조분석을 수행합니다."
- "일부 기능은 이미 시연 가능한 수준으로 완료되었고, 감지 범위와 정확도는 계속 확장 중입니다."

## 영상에서 피해야 할 표현

- "모든 메신저를 완벽하게 감지합니다."
- "모든 위험 대화를 정확히 이해합니다."
- "완전히 학습된 AI가 전체 판단을 수행합니다."

## 완료 기준 대조

- 영상 시연에서 완료 기능으로 설명할 항목이 정리되어 있음
- 영상 시연에서 확장 중 기능으로 설명할 항목이 정리되어 있음
- 과장 표현과 금지 표현이 분리되어 있어 팀원별 설명 차이를 줄일 수 있음
