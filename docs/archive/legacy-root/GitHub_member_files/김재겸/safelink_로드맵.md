## 운영 원칙

1. **1주 단위 스프린트** - 매주 문서/화면/기능/데모 중 최소 1개 산출물을 남긴다
2. **스펙 먼저, 구현 나중** - 만들기 전에 기능 스펙을 먼저 작성한다
3. **AI는 스펙 기반으로 활용** - 막연한 요청 대신 정리된 스펙으로 코드·문서 초안을 요청한다
4. **팀원 검토 필수** - AI 결과물은 그대로 쓰지 않고 팀원 검토 후 수정한다
5. **작은 단위로 완성** - 큰 기능을 한 번에 끝내지 않고 1주 안에 끝낼 크기로 나눈다
