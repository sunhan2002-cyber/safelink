# 김선한 6주차 숙제 03 - 백그라운드 감지 기능 요구사항

## 1. 기능 목적

백그라운드 감지 기능은 사용자가 앱을 직접 열지 않은 상태에서도 위험 신호를 빠르게 감지하고, 필요할 때 즉시 알림으로 연결하기 위한 기능이다.

이번 주 기준에서 중요한 것은 `완전 자동 감지 완성`이 아니라, `어디에서 감지하고 어디로 연결할지 구조를 확정하는 것`이다.

## 2. 기능 위치

- 사용자가 설정 화면에서 백그라운드 감지 기능을 켠다.
- 감지 기능은 별도 서비스 구조로 동작한다.
- 위험도 기준을 충족하면 알림을 띄운다.
- 사용자가 알림을 누르면 결과 화면 또는 대응 가이드 화면으로 이동한다.

## 3. 기본 구조

```text
설정에서 기능 ON
-> MessageDetectionService 동작
-> 화면 또는 메시지 텍스트 감지 시도
-> 1차 규칙 기반 분석
-> 필요 시 2차 AI API 보조 분석
-> 위험도 기준 충족 시 RiskNotifier로 알림
-> 알림 클릭
-> DetectionResultScreen 또는 ResponseGuideScreen 이동
```

## 4. 김재겸 6week 기준 반영 항목

- `background/MessageDetectionService.kt`
  - 감지 -> 분석 -> 알림 골격을 담는 서비스 스켈레톤
- `notification/RiskNotifier.kt`
  - 위험도별 알림 표시 구조
- `AndroidManifest.xml`
  - 서비스 선언 및 권한 설정 위치
- `accessibility_service_config.xml`
  - 접근성 서비스 구성 파일
- `docs/FeatureExtension.md`
  - 기능확장 파트 설명 문서

## 5. 이번 주 요구사항

### 반드시 정리되어야 하는 것

- 어떤 조건에서 감지를 시작하는지
- 감지한 텍스트를 어느 분석 흐름으로 보낼지
- 어느 위험도 이상에서 알림을 띄울지
- 알림 클릭 시 어느 화면으로 보내는지
- 사용자가 켜고 끄는 설정 위치가 어디인지

### 이번 주에 아직 완성까지 요구하지 않는 것

- 모든 앱을 대상으로 한 완전 자동 감지
- 실시간 상시 감지의 안정성 완성
- OS 정책 대응 최종본
- 실제 운영 수준의 배터리 최적화

## 6. 분석확장과의 연결 기준

- 백그라운드 감지라고 해서 별도 분석 엔진을 만들지 않는다.
- 감지된 텍스트도 일반 입력과 같은 분석 기준을 사용한다.
- 먼저 `1차 규칙 기반 분석`을 적용한다.
- 규칙 기반으로 판단이 애매한 경우에만 `2차 AI API 보조 분석`을 붙인다.
- 최종 결과 데이터 구조는 DetectionResult와 같은 기준을 유지해야 한다.

## 7. 알림 기준

### 현재 기준

- SAFE는 알림을 띄우지 않는 방향이 기본이다.
- CAUTION은 팀 논의 후 알림 여부를 결정한다.
- WARNING 이상은 알림 후보로 본다.
- CRITICAL은 즉시 확인이 필요한 단계로 본다.

### 알림 문구 기준

- 과도하게 단정적인 표현은 피한다.
- 범죄명 확정 문구보다 `확인이 필요한 위험 신호` 중심으로 표현한다.
- 상세 문구는 김우영 문구 기준과 통일한다.

## 8. 사용자 설정 항목

- 백그라운드 감지 ON/OFF
- 알림 사용 여부
- 생체 인증 또는 잠금과 함께 사용할지 여부
- 감지 시 어떤 화면으로 우선 이동시킬지

## 9. 월요일 전 다시 점검할 쟁점

- 감지 텍스트를 어떤 범위까지 읽는지
- 접근성 서비스 사용 범위를 어디까지 허용할지
- 감지 즉시 분석할지, 일정 기준 이상 누적 시 분석할지
- 알림 클릭 시 결과 화면으로 갈지, 대응 가이드로 바로 갈지
- AI API 보조 분석을 백그라운드에서도 바로 사용할지

## 10. 구현 완료 판단 기준

- 백그라운드 감지 기능이 코드상 어느 위치에 들어가는지 설명 가능해야 한다.
- 감지 -> 분석 -> 알림 -> 화면 이동 구조가 한 문서로 이해 가능해야 한다.
- 김재겸 구현 구조와 김선한 문서 기준이 충돌하지 않아야 한다.
- 팀원들이 이 문서를 보고 같은 기준으로 후속 구현을 이어갈 수 있어야 한다.

## 11. 한 줄 결론

백그라운드 감지 기능의 이번 주 목표는 `완성`이 아니라, `실제 앱 안에서 어떤 서비스와 어떤 화면 흐름으로 붙을지 기준을 확정하는 것`이다.
