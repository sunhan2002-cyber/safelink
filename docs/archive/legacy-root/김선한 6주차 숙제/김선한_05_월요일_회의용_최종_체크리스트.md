# 김선한 6주차 숙제 05 - 월요일 회의용 최종 체크리스트

## 1. 회의 목표

2026년 8월 3일 월요일 대면 회의에서는 아래를 최종 확인해야 한다.

- 기능확장과 분석확장 기준이 하나의 흐름으로 연결되는지
- 팀원 결과물이 서로 충돌하지 않는지
- 월요일 이후 바로 개발과 병합을 시작할 수 있는지

## 2. 전체 흐름 체크

- [ ] `텍스트 입력 -> 분석 -> 결과 -> 가이드` 흐름이 유지되는가
- [ ] `스크린샷 입력 -> OCR -> 분석 -> 결과 -> 가이드` 흐름이 연결되는가
- [ ] `백그라운드 감지 -> 분석 -> 알림 -> 결과/가이드` 흐름이 설명 가능한가
- [ ] 세 흐름이 최종적으로 하나의 결과 구조로 모이는가

## 3. 기능확장 체크

- [ ] 스크린샷 분석 시작 위치가 확정됐는가

- [ ] 백그라운드 감지 서비스 위치가 정리됐는가
- [ ] 알림 구조가 정리됐는가

## 4. 분석확장 체크
