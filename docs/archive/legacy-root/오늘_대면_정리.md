# 오늘 대면 정리

## 오늘 대면 목표

- 기술스택별 역할 정리
- 피그마로 앱 화면 초안 제작
- 내일부터 바로 개발 들어갈 수 있게 화면/데이터/API 초안 확정

## 우리가 지금까지 한 것

- 노션 정리
- 로드맵 정리
- 교수님 질문했던 내용 답변 정리

## 현재 단계

- 아직 구현 전 준비 단계에 가까움
- 오늘은 `설계 마감 + 피그마 초안 + 역할 분담`까지 하는 게 목표

## 정리된 기술스택

- `XML`: 화면 레이아웃, 화면 모양 구성
- `Kotlin`: 화면 동작, 버튼 반응, 화면 전환
- `Java`: 점수 계산, 데이터 처리, 저장 로직, 앱 내부 기능
- `Python + FastAPI(또는 Flask)`: 위험 문장 분석, 추천 로직, 서버 응답 처리
- `Android Studio`: 전체 앱 개발 환경
- `SQLite`: 앱 내 구조화 데이터 저장
- `SharedPreferences`: 단순 설정값 저장
- `Android Notification + Foreground Service`: 백그라운드 감지 알림
- `BiometricPrompt`: 앱 잠금/생체인증
- `ngrok`: 데모용 서버 외부 연결
- `OCR`: 스크린샷에서 텍스트 추출
- `키워드/규칙 기반 위험 분석`: 위험 표현 사전 + 규칙 + 가중치 합산
- `Figma`: 앱 화면 초안 제작

## 오늘 기술스택별 할 일

### 1. Figma

- 앱 화면 초안 그리기
- 우선 그릴 화면
  - `Home`
  - `자가진단`
  - `자가진단 결과`
  - `텍스트 감지 입력`
  - `텍스트 감지 결과`
  - `대응 가이드`
  - `기관 연결`
  - `긴급 요청`
  - `설정`
  - `잠금 화면`

### 2. XML

- 각 화면에 들어갈 UI 구성요소 정리
- 버튼, 입력창, 카드, 하단 네비게이션 구조 정리

### 3. Kotlin

- 화면 전환 흐름 정리
- 어떤 버튼을 누르면 어디로 이동하는지 정의

### 4. Java

- 위험도 점수 계산 방식 초안 정리
- 체크리스트 결과, 감지 결과, 메모 저장 구조 정리

### 5. Python + FastAPI

- 서버 요청/응답 형식 정리
- 위험 문장 분석 흐름 초안 정리

### 6. SQLite

- 저장할 데이터 구조 정리
- 예시
  - 자가진단 결과
  - 텍스트 감지 기록
  - 상황 메모
  - 추천 기관 목록

### 7. SharedPreferences

- 저장할 설정값 정리
- 예시
  - 잠금 여부
  - 생체인증 여부
  - 긴급 연락처
  - 알림 문구

### 8. Notification + Foreground Service

- 위험 단계별 알림 문구 정리
- `주의 / 경고 / 긴급` 단계 동작 구분

### 9. BiometricPrompt

- 잠금 해제 흐름 정리
- `PIN + 생체인증` 사용 방식 정리

### 10. OCR

- 스크린샷 → 텍스트 추출 흐름 정리
- OCR을 앱 내부에서 할지, 서버에서 할지 결정

### 11. ngrok

- 발표 때 서버 연결 방식 정리
- 앱이 어느 URL로 통신할지 합의

## 오늘 꼭 정해야 하는 것

- 역할 분담

## 오늘 기준 로드맵 해석

- 오늘은 `구현 시작` 단계가 아니라 `기획 단계 마무리`에 더 가까움
- 지금까지 한 것은 주로 노션 정리, 로드맵 정리, 교수님 질문 답변 정리
- 그래서 오늘 목표는 큰 개발보다 `기획 결과물 확정 + 피그마 초안 착수`로 잡는 게 맞음
