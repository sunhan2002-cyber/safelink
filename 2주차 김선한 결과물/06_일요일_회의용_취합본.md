# 일요일 회의용 취합본

## 목적

이번 주까지 각 팀원이 준비한 결과물과 일요일 회의 전까지 마무리해야 할 과제를 한 번에 확인하기 위한 문서다.
회의에서는 이 문서를 기준으로 결과물 점검, 부족한 부분 확인, 다음 주 개발 시작 범위를 확정한다.

## 이번 주 공통 목표

- 필수 화면 확정
- 화면 흐름 확정
- 위험도 계산 방식 v1 확정
- keywords.json v1 확보
- institutions.json 구조 초안 확보
- API 초안 확보
- 다음 주 바로 개발할 화면/기능 우선순위 확정

## 현재까지 정리 완료된 문서

- `01_필수_화면_목록_최종본.md`

## 회의에서 반드시 확인할 항목

### 1. 필수 화면 확정

- 현재 12개 필수 화면으로 확정할지
- 후순위 화면은 무엇으로 둘지

### 2. 화면 흐름 확정

- 자가진단 흐름
- 분석 흐름
- 대응/지원 흐름
- 기록/설정 흐름

### 3. 위험 분석 기준 확정

- 위험 카테고리 명칭
- 위험도 계산 방식
- keywords.json v1 구조

### 4. 추천 데이터 기준 확정

- institutions.json 구조
- 기관 정보 필드명
- 추천 화면에서 보여줄 항목

### 5. API 기준 확정

- `/health`
- `/analyze`
- `/recommend/institutions`

### 6. 다음 주 개발 범위 확정

아래 중 최소 1개 핵심 흐름이 실제로 동작하도록 하는 것을 목표로 한다.

- `홈 -> 자가진단 -> 결과 -> 대응 가이드 또는 지원 연결`
- `홈 -> 분석 입력 -> 결과 -> 대응 가이드 또는 지원 연결`

## 현재 기준 최종 판단

우리 팀은 지금 `아무것도 없는 상태`는 아니다.
기획, 분석 기준, 피그마 초안, 데이터/문구 초안은 이미 존재한다.

이번 주 일요일 회의의 핵심은 새로 처음부터 만드는 것이 아니라,

- 흩어진 결과물을 하나의 기준으로 묶고
- 빠진 항목을 채우고
- 다음 주 실제 개발 가능한 수준으로 확정하는 것

이다.

## 회의용 한 줄 정리

이번 주 회의 목표는 SafeLink의 화면, 분석 기준, 데이터 구조, API 기준을 확정해서 다음 주부터 핵심 흐름 구현에 바로 들어갈 수 있는 상태를 만드는 것이다.
