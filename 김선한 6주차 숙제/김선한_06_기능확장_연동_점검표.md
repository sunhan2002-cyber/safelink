# 김선한 6주차 숙제 06 - 기능확장 연동 점검표

## 1. 문서 목적

이 문서는 김선한과 김재겸이 맡은 기능확장 파트를 기준으로, 외부 연동 대상과 충돌 가능성을 간단히 확인하는 점검표다.

즉 이 문서는 `전체 팀 총괄 문서`가 아니라 `기능확장 파트가 다른 결과물과 붙을 때 확인할 항목`을 정리한 부속 문서다.

## 2. 기능확장 내부 점검

- [ ] 스크린샷 분석 시작 위치가 명확한가
- [ ] OCR 결과가 기존 분석 흐름으로 넘어가는 방식이 명확한가
- [ ] 백그라운드 감지 기능이 어떤 서비스 구조로 붙는지 명확한가
- [ ] 알림 이후 이동 화면 기준이 정리됐는가

## 3. 외부 연동 기준 확인 항목

### 신기훈 결과물과 붙을 때 확인할 것

- [ ] 규칙 기반 분석 결과를 기능확장 흐름에서 그대로 받을 수 있는가
- [ ] OCR 결과를 넘길 데이터 형식이 크게 충돌하지 않는가
- [ ] AI API 보조 분석 진입 조건을 기능확장 쪽에서 이해 가능한가

### 김우영 결과물과 붙을 때 확인할 것

- [ ] 결과 화면 문구 기준이 기능확장 흐름과 충돌하지 않는가
- [ ] 대응 가이드 문구 기준이 기능확장 흐름과 충돌하지 않는가
- [ ] 백그라운드 감지 알림 문구를 어디 기준으로 맞출지 정리됐는가

## 4. 월요일인 2026년 8월 3일 대면 회의에서 확인할 것

- [ ] 스크린샷 분석 흐름과 기존 분석 흐름을 하나로 설명할 수 있는가
- [ ] 백그라운드 감지 기능이 앱 안에서 어디에 붙는지 설명할 수 있는가
- [ ] 김재겸이 구현할 범위와 김선한이 정리한 기준 문서가 맞물리는가
- [ ] 다른 팀원 결과물은 기능확장 파트의 연동 참고 기준으로만 보면 되는가

## 5. 한 줄 결론

이 점검표의 목적은 다른 팀원 숙제를 대신 관리하는 것이 아니라, 기능확장 파트가 월요일 구현 단계에서 막히지 않도록 필요한 연동 포인트만 확인하는 것이다.
