Safelink 로드맵

프로젝트명
- Safelink

주제
- 위험한 관계를 감지하는 순간, 필요한 도움을 찾아 손을 내미는 앱

서비스 한줄 소개
- 관계 위험 신호 탐지와 복지 연결을 하나의 흐름으로 연결하고, 위험 감지 후 적절한 지원 제도를 추천하며 신청까지 동행하는 앱
- 백그라운드 상태에서 메신저 대화를 분석해 위험 신호를 빠르게 감지하고 즉시 알림까지 제공하는 안전 지원 앱

대회 일정 기준 핵심 목표
- 2026년 8월 28일(금) 16시까지 1차 심사 제출물 완성
- 제출 대상: 10분 이내 소개 동영상, 작품 결과 보고서, 작품 안내 팜플렛
- 2026년 9월 4일(금) 1차 결과 발표 대비
- 2026년 9월 17일(목) 본선 발표 가능 수준의 데모 준비

핵심 기능
1. 위험 신호 감지
- 체크리스트 기반 자가 진단
- 관계 상황 기록을 통한 위험도 분류
- 카카오톡, 메신저 사용 중 위험 표현이나 반복 패턴 감지
- 앱 백그라운드 실행 중 위험 대화 감지 시 배너 알림 제공

2. 맞춤 지원 매칭
- 위험 유형별 상담 기관, 복지 제도, 보호 서비스 추천
- 사용자 상황에 맞는 지원 경로 안내

3. 신청 동행 기능
- 기관 연락 방법 안내
- 신청 절차, 필요 서류, 준비 항목 정리

4. 긴급 대응 및 기록
- 긴급 도움 요청 버튼
- 상황 메모 및 기록 보관

5. 실시간 감지 알림
- 위험 문장, 협박, 통제, 반복 압박 등 대화 패턴 탐지
- 위험 수준에 따라 주의, 경고, 긴급 단계로 구분
- 배너 클릭 시 대응 가이드와 연결 가능한 지원 제도 화면으로 이동

6. 보안 및 프라이버시 보호
- 앱 실행 시 비밀번호 또는 생체인증으로 접근 제한
- 민감한 기록 화면 진입 시 추가 인증 제공
- 앱 아이콘 또는 알림 문구를 일반적인 형태로 설정할 수 있는 보호 옵션 고려
- 사용자 기록과 위험 정보는 외부 노출을 최소화하도록 보호

개발 로드맵
1. 기획 단계
- 문제 정의와 주요 사용자 설정
- 위험 상황 시나리오 정리
- 차별점 한 문장으로 정리

2. 설계 단계
- 사용자 흐름도 작성
- 화면 구조와 기능 우선순위 확정
- 위험 감지 후 지원 연결 로직 설계
- 백그라운드 감지 방식과 알림 시나리오 설계
- 앱 잠금, 생체인증, 민감 화면 보호 시나리오 설계

3. 프로토타입 단계
- 핵심 화면 시안 제작
- 위험 체크, 지원 매칭, 신청 동행 기능 구현
- 시연 가능한 앱 데모 완성
- 실시간 위험 감지 알림 데모 구현
- 비밀번호 및 생체인증 기반 앱 잠금 기능 구현

4. 제출 준비 단계
- 10분 이내 소개 동영상 구성
- 작품 결과 보고서 초안 작성
- 작품 안내 팜플렛 핵심 문구 정리
- 보안 기능의 필요성과 사용자 보호 가치 정리

5. 발표 대비 단계
- 예상 질문 정리
- 본선용 발표 스크립트 준비
- 데모 안정화 및 역할 분담 점검

우선순위
1. 위험 감지에서 지원 연결까지 이어지는 흐름을 명확히 보여주기
2. 실제 도움이 되는 서비스라는 점을 기능과 시연으로 증명하기
3. 대회 제출물 3종을 앱 개발과 함께 병행 준비하기
4. 백그라운드 감지와 즉시 배너 알림 기능을 핵심 차별점으로 강조하기
5. 앱 노출 자체가 위험한 사용자를 위한 접근 보호 기능을 포함하기

바로 해야 할 일
- 앱 핵심 사용자 시나리오 3개 정리
- 필수 화면 목록 작성
- 결과 보고서 목차 초안 만들기
- 소개 영상 스토리보드 초안 만들기
- 실시간 위험 대화 예시와 알림 문구 초안 만들기
- 비밀번호, 생체인증, 숨김형 알림 문구 초안 만들기
