# 교수님 질문 답변 정리

## 교수님 질문 1. 우리 앱이 LLM AI와 차별점이 무엇인가?

SafeLink는 범용 대화형 AI가 아니라, 디지털 위험 상황에 특화된 안전 지원 서비스이다.

일반적인 LLM AI는 다양한 질문에 대해 폭넓은 답변을 생성하는 범용 모델이지만, SafeLink는 보이스피싱, 로맨스 스캠, 가스라이팅, 협박, 사칭과 같은 위험 대화 신호를 감지하고 그 결과를 바탕으로 대응 가이드와 지원 기관 연결까지 제공하는 데 목적이 있다.

즉, SafeLink의 차별점은 단순한 답변 생성형 AI가 아니라,

위험 감지 → 위험도 분류 → 대응 안내 → 기관 연결

까지 이어지는 서비스 구조에 있다.

## 교수님 질문 2. 데이터는 어디서 오는가?

데이터는 공개 자료와 직접 정리한 예시 데이터에서 확보할 계획이다.

활용 가능한 데이터는 다음과 같다.

- 금융감독원, 경찰청 등에서 공개한 보이스피싱 및 사기 사례
- AI Hub 등의 공개 데이터셋
- 공개된 스팸 문자 및 사칭 사례 자료
- 팀이 직접 정리한 위험 상황 시나리오
- 개인정보가 포함되지 않은 합성 예시 대화 데이터

또한 실제 서비스에서는 정상 대화와 위험 대화를 함께 고려해야 하므로, 위험 사례뿐 아니라 비교 기준이 되는 일반 대화 예시도 함께 정리할 필요가 있다.

## 교수님 질문 3. AI를 어떻게 학습시킬 것인가?

초기 단계에서는 OCR로 추출한 텍스트를 바탕으로 키워드/규칙 기반 분석을 먼저 적용한다.

위험 표현, 반복 압박, 협박, 송금 요구, 사칭 표현 등을 사전과 규칙으로 정리하고, 가중치 점수를 합산하여 위험도를 분류하는 방식이다.

이후에는 공개 데이터와 직접 정리한 라벨링 데이터를 바탕으로, 한국어 사전학습 모델이나 경량 머신러닝 모델을 활용해 위험 문장 분류 성능을 높이는 방향으로 확장할 수 있다.

즉 처음부터 거대한 AI를 새로 만드는 것이 아니라, 초기에는 규칙 기반으로 시작하고 이후 필요한 범위에서 학습 기반 모델로 고도화하는 방식이다.
