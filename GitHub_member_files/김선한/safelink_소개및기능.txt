Safelink 소개 및 기능 정리

앱 이름
- Safelink

앱 소개
- Safelink는 위험한 관계의 신호를 빠르게 감지하고, 사용자가 필요한 도움을 안전하게 받을 수 있도록 지원하는 앱이다.
- 단순히 위험을 경고하는 데서 끝나지 않고, 상담 기관, 복지 제도, 보호 서비스와 같은 실제 지원으로 연결해 주며 신청 과정까지 동행하는 것을 목표로 한다.
- 특히 메신저 대화나 반복적인 관계 패턴 속에서 나타나는 위험 표현을 감지하고, 사용자가 즉시 대응할 수 있도록 배너 알림과 대응 가이드를 제공한다.
- 또한 가정폭력이나 통제적 관계처럼 앱 사용 사실이 노출되는 것 자체가 위험할 수 있는 상황을 고려하여 비밀번호와 생체인증 같은 보안 기능도 함께 제공한다.

서비스 핵심 가치
- 위험 신호를 조기에 발견할 수 있다.
- 위험 감지 후 바로 대응 행동으로 이어질 수 있다.
- 상황에 맞는 상담 기관과 복지 제도를 연결받을 수 있다.
- 사용자의 안전과 프라이버시를 함께 보호할 수 있다.

주요 기능

1. 위험 관계 자가진단
- 체크리스트를 통해 사용자가 현재 관계의 위험 신호를 직접 점검할 수 있다.
- 응답 결과를 바탕으로 위험도를 분류해 보여준다.

2. 위험 대화 감지
- 메신저나 채팅 상황에서 협박, 통제, 반복 압박, 불안 유발 표현 등을 감지한다.
- 키워드 기반 또는 규칙 기반 방식으로 위험 신호를 분석한다.

3. 백그라운드 감지 및 배너 알림
- 앱을 백그라운드로 켜 둔 상태에서 위험 신호가 감지되면 즉시 배너 알림을 보낸다.
- 위험 단계는 주의, 경고, 긴급으로 나누어 보여준다.

4. 대응 가이드 제공
- 위험이 감지되었을 때 사용자가 바로 취할 수 있는 행동을 안내한다.
- 대응 가이드 보기, 상담 기관 연결, 긴급 도움 요청 등의 행동 버튼을 제공한다.

5. 맞춤 지원 매칭
- 사용자 상황과 위험 유형에 따라 상담 기관, 복지 제도, 보호 서비스를 추천한다.
- 단순 정보 제공이 아니라 실제 도움으로 이어질 수 있도록 연결 경로를 제시한다.

6. 신청 동행 기능
- 지원 제도 신청 절차, 준비 서류, 진행 방법을 안내한다.
- 사용자가 혼자 복잡한 절차를 찾지 않도록 돕는다.

7. 긴급 도움 요청
- 위급한 상황에서 빠르게 도움 요청 화면으로 이동할 수 있다.
- 긴급 연락 또는 즉시 행동이 가능하도록 단순하고 빠르게 구성한다.

8. 상황 기록 및 조회
- 사용자가 겪은 상황이나 위험 대화를 메모 형태로 저장할 수 있다.
- 이후 감지 기록과 함께 다시 확인할 수 있다.

9. 보안 기능
- 앱 실행 시 비밀번호 잠금 기능을 제공한다.
- Face ID 또는 지문 같은 생체인증을 통해 본인만 접근할 수 있도록 한다.
- 민감한 기록 화면은 추가 인증이 가능하도록 설계한다.
- 알림 문구는 직접적인 위험 내용을 노출하지 않도록 중립적으로 구성할 수 있다.

예상 사용자
- 연인 관계, 가족 관계, 지인 관계 등에서 불안과 통제를 경험하는 사용자
- 위험한 관계인지 스스로 판단이 어려운 사용자
- 도움을 받고 싶지만 어디서부터 시작해야 할지 모르는 사용자
- 위험 상황에서 안전하게 기록하고 지원을 연결받고 싶은 사용자

차별점
- 위험 감지에서 끝나지 않고 실제 지원 연결까지 이어진다.
- 백그라운드 감지와 배너 알림으로 즉시 대응을 유도한다.
- 보안 기능을 통해 앱 접근 자체도 안전하게 보호한다.
- AI 협업 기반 분석 로직과 안드로이드 앱 구조를 결합해 실현 가능성을 높인다.

한줄 요약
- Safelink는 위험한 관계를 감지하고, 안전하게 도움을 연결하며, 사용자의 행동까지 이어지도록 돕는 보호형 지원 앱이다.
