# Safelink 1주차 역할 분담

## 기준

- 현재 팀이 합의한 기준은 `1주차 안에 끝낼 수 있는 산출물 중심 역할 분담`이다.
- 장기 직군 분담보다, 이번 주에 바로 결과물을 만들 수 있는 업무로 나눈다.
- 현재 확정된 기준 문서는 `프로젝트_설명문서_초안.md`, `교수님_질문_답변_정리.md`, 노션 정리 내용이다.

## 1주차 역할 분담

### 김선한

- 문제 정의 문장 정리
- 주요 사용자 정리
- 교수님 질문 3가지 답변 문장 다듬기
- 차별점 한 문장 확정

### 신기훈

- 위험 상황 시나리오 3개 초안 정리
- 위험 키워드 카테고리 초안 정리
- 위험도 계산 방식 초안 정리
- `keywords.json`에 들어갈 항목 틀 정리

### 김재겸

- 피그마로 메인 화면 초안
- 자가진단 / 감지 / 기관연결 화면 러프
- 필수 화면 목록 정리
- 화면 흐름 초안 정리
- 버튼 / 카드 / 입력창 같은 UI 구성 정리

### 김우영

- 화면별 필요한 기능 메모
- 저장해야 할 데이터 항목 초안 정리
- 알림 문구 / 설정 문구 초안 정리
- 전체 정리 보조 및 문서 취합
