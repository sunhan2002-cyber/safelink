# AI 보조분석 검증 (오탐·놓침 회귀 검사)

키워드나 임계값을 고친 뒤, **AI 보조분석이 판정을 나쁘게 만들지 않는지** 확인하는 스크립트입니다.
지금까지는 개인 PC의 임시 폴더에만 있어서 팀원이 돌릴 수 없었는데, 저장소로 옮겨 누구나 같은 기준으로 다시 돌릴 수 있게 했습니다.

## 무엇을 보는가

테스트 세트의 `expected_level`은 "규칙 엔진이 내야 할 점수 구간"이지 실제 위험의 정답이 아닙니다.
그래서 등급 일치율 대신 **두 방향의 변화**만 봅니다.

1. 일상 대화를 AI가 위험 쪽으로 올리는가 → **오탐 증가**
2. 사기 문구를 AI가 안전 쪽으로 내리는가 → **놓침 증가**

앱에서 실제로 AI를 부르는 조건(회색지대)에 해당하는 케이스만 따로도 집계합니다.

## 실행

```bash
cd safelink
pip install -r backend/requirements.txt
python tools/ai_eval/run_ai_eval.py
```

- API 키는 환경변수 `ANTHROPIC_API_KEY`를 먼저 보고, 없으면 `android/local.properties`에서 읽습니다. 화면에 출력하지 않습니다.
- 인자를 주면 다른 케이스 파일로 돌릴 수 있습니다: `python tools/ai_eval/run_ai_eval.py 내케이스.json`
- 앱과 같은 조건으로 호출합니다 — `backend/claude_analyzer.py`의 규칙(앱 `ClaudeAnalysisRules`와 동일), claude-sonnet-5, effort low, 전화번호·링크 마스킹, 보정치 ±30.

## 파일

| 파일 | 설명 |
|---|---|
| `run_ai_eval.py` | 실행 스크립트 |
| `cases.json` | 케이스 43건(일상 12 / 사기 31, 그중 앱이 AI를 부르는 건 18건). 각 케이스에 온디바이스 점수·매칭 id가 들어 있어 앱과 같은 입력으로 호출합니다 |
| `result_20260911.md` | 2026-09-11 실행 결과(기준선) |
| `cases_ai.json`, `cases_report.md` | 실행하면 생기는 결과 파일(케이스 파일 이름 기준) |

## 기준선 (2026-09-11)

- 호출 43건 전부 성공, 평균 4.1초 / 최대 6.5초
- 일상 대화 12건: AI가 등급을 올린 경우 **0건**
- 사기 문구 31건: AI가 등급을 내린 경우 **0건** (4건은 위험 쪽으로 올림)

단, 등급이 그대로여도 **점수가 내려간 사기 케이스가 4건** 있었습니다(가장 큰 건 25점 → 5점).
전부 한 문장짜리 짧은 케이스라 AI가 볼 맥락이 적었던 것으로 보입니다. 보고할 때는
"AI가 등급을 잘못 바꾼 적은 0건"이라고 쓰고, "점수를 절대 내리지 않는다"고는 쓰지 마세요.

## 비용

케이스 1건당 Claude 호출 1회입니다. 43건 전체 실행은 소액이지만 공짜는 아니니, 키워드를 크게 고친 뒤에만 돌리는 걸 권합니다.

## 마스킹 A/B (`masking_ab/`)

"개인정보를 더 가리면 AI 판단이 나빠지는가"를 실제로 재본 기록입니다.

```bash
python tools/ai_eval/masking_ab/masking_ab.py
```

- `cases_pii.json` — 전화번호·링크·계좌번호·주민등록번호·카드번호·이메일이 들어간 대화 12건(사기 8 / 일상 4).
  각 건에 규칙 엔진 점수와 두 가지 마스킹 결과(A: 예전 방식, B: 현재 `PrivacyMasker`)가 들어 있습니다.
- `result_20260912.json` — 2026-09-12 실행 결과.

### 이때 확인한 것

| 마스킹 방식 | 결과 |
|---|---|
| 링크를 **통째로** `[링크]` 로 가림 | 스미싱 문자에서 AI 보정이 크게 떨어짐 (부고 스미싱 +28 → +8). 도메인이 판단 근거였기 때문 |
| 링크의 **경로만** 가리고 도메인은 남김(채택) | 보정치 차이 평균 1.4점, 최대 5점. 등급이 바뀐 케이스 0건 |

그래서 `PrivacyMasker` 는 `[링크: funeral-notice.top]` 처럼 도메인을 남깁니다.
금액과 이름도 판단에 필요해서 가리지 않습니다.
